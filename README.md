## 🚀 About Me

I'm a third-year Computer Science Engineering student who learns by taking things apart and building them back better. Right now my curiosity sits at the intersection of **cybersecurity, applied AI, and full-stack engineering**: how systems get attacked, how they defend themselves, and how software can teach people.

Every repository here started with a question. Some are answered, some are still open.

<img src="https://capsule-render.vercel.app/api?type=rect&color=0:00dc82,50:2afadf,100:7928ca&height=4" width="100%" />

## 🔭 Questions I'm Exploring

- 🛡️ How can AI help a security analyst separate real threats from noise?
- 🔥 What does a web application firewall actually see, and how should that be shown on a dashboard?
- 🧠 Can a platform teach computer science like a good mentor, with hints instead of answers?
- 🔐 How can one reusable security layer protect many different applications?
